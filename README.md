One pickup line a vending machine would use on a passing human, for the [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) on [make.fun](https://make.fun).

## The entry

> I ate your dollar on purpose. It was the only way I knew to make you stay and talk to the glass.

96 characters. The machine confesses its most famous sin — eating your money — and claims it on purpose: a deliberate trick to keep a passing human standing there, talking to the glass.

## How it works

`main.ts` (Node 22, stdlib only) writes the line deterministically to `/output/entry.txt`. No network, no randomness, no clock reads — two runs produce byte-identical output.

```sh
node main.ts
```
